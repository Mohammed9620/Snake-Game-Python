# 🐍 Snake Game - Python (OOP)

This is a classic **Snake Game** built using **Python** and the **Turtle Graphics** library. The project demonstrates the use of Object-Oriented Programming (OOP) principles and persistent data storage for high scores.

## ✨ Features
* **Scoring System**: Real-time score tracking as the snake grows.
* **Persistent High Score**: The game reads from and writes the highest score to a local file (`data.txt`), ensuring your record is saved even after closing the program.
* **Dynamic Visuals**: The food changes both its shape and color randomly every time it is eaten.
* **Responsive Controls**: Smooth movement handling using keyboard arrow keys.

## 🛠️ Technologies Used
* **Python 3**
* **Turtle Graphics Library**
* **File I/O**: For reading and updating the high score in `data.txt`.
* **OOP**: Logic is organized into classes like `Snake`, `Food`, and `Score`.

## 🚀 How to Run
1. Ensure you have Python 3 installed.
2. Download all files into the same folder.
3. Run: `python main.py`.
